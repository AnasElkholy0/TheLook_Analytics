# Local data

Download the Looker E-commerce dataset from [Kaggle](https://www.kaggle.com/datasets/mustafakeser4/looker-ecommerce-bigquery-dataset) and place local copies in `data/raw/`. This folder is intentionally excluded from Git so raw data and user-level records are not published.

The analysis reference workbook contains `orders`, `order_items`, `users`, `events`, and `inventory_items`, along with derived fields and dashboard summaries. The source download may not contain every derived field shown in the workbook.
